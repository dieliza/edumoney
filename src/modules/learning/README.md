# Aprende

Contenido editorial versionado, ejercicios e historial local cifrado. Una respuesta correcta confirma la versión de la lección; volver a pendiente conserva intentos.
El módulo usa la cola de MoneyStore y no crea movimientos financieros. La voz iOS usa una voz española básica disponible; Android conserva texto cuando no se puede comprobar que el motor sea local.
Los simuladores separados en `../decisions` guardan inputs y fórmula versionada, no registros reales de compras/préstamos. Ver docs/stages/07.md.
