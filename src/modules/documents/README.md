# Escaneo, voz y documentos

Adaptadores nativos de captura, OCR local y dictado con requisito local. Formularios de revisión, imagen opcional en SQLCipher, huella y vínculos transaccionales sin duplicar movimientos.
La entrada manual está siempre disponible. Cambiar una imagen no cambia una transacción; una corrección financiera autorizada conserva IDs y deja los comprobantes pendientes de revisión.
No se conservan audios ni se usa almacenamiento remoto. Los parches nativos y permisos se explican en docs/stages/08.md y docs/SECURITY.md.
