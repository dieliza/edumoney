# Web dictation result delivery — 2026.11.16.9

Only browser voice capture changed. Continuous recognition keeps listening across pauses until stop/end; interim text remains available. Stop requests made before the browser start callback are queued, preventing stopping a recognizer while its microphone permission/startup is pending. Graceful stop allows 15 seconds for final text instead of aborting after three seconds. Empty termination now explicitly reports failure to receive transcription instead of saying dictation finished successfully. Aborting or leaving still suppresses late private callbacks. No audio persistence, new provider, API calls, financial logic or native recognizer changes.

Focused verification: 15/100 cases executed, all passed, including final text delayed five seconds after stop, permission/startup stop ordering, empty-result feedback, Safari's prefixed API, privacy cleanup and single-button semantics. TypeScript, ESLint, web build and worker syntax checked before publication. No physical Safari/iPhone/Android audio test available; automated tests simulate browser events and do not establish provider availability or microphone permissions on the user's device.
