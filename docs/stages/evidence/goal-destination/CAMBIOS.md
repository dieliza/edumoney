# Destinos de Mis metas

Cambio de producto limitado a TransferEditor: las opciones de destino vinculadas a goals se identifican como «Mis metas · nombre · balance». Se mantienen los identificadores reales de cada fondo, la lista de origen, los importes automáticos, la confirmación, las validaciones, la prevención de doble pulsación y el registro de transferencias existente. No se crea un fondo genérico ni se añaden cantidades directamente a metas. No se modifican ingresos, gastos, presupuesto ni pistas.

Las pruebas verifican la selección de una meta, su identificador real, importe, origen y guardado único, además de la actualización de meta/progreso y balance mediante SQLite con datos ficticios. Se corrigió una expectativa antigua del test de edición vigente para aceptar su tercer argumento opcional undefined, ya presente en la implementación anterior. No se alteró esa operación del producto.

TypeScript y ESLint de archivos afectados aprobados. Paquete limitado a la fábrica 21025; todas las otras 1442 fábricas se conservan byte por byte. Se reutiliza el empaquetado de rutas y contenido ya publicado, con nueva caché, alias coherentes y manejadores push/activación conservados. No hay migraciones. No se utilizaron datos financieros reales. Sin navegador interactivo: no se afirma prueba física.

El archivo de despliegue excede el espacio persistente disponible. Se compila y valida en memoria, se envía el commit exacto y se usa compilación remota para publicar.
