# Presupuesto mensual como simulación aislada

Ingresos proyectados y cantidades de categorías vuelven a ser editables con centavos automáticos. Se retiran transferencias, aportaciones a fondos/metas, reservas reales e historial de transferencias de esta pantalla; sus funciones y registros permanecen en las herramientas de dinero existentes.

Guardar, editar, copiar y eliminar presupuestos solo modifica budget_plans y budget_plan_revisions. Se retira el puente que escribía o borraba límites monthly_budgets. Los gastos anuales simulados no crean facturas, no enlazan fondos ni realizan reservas. La comparación con ingresos/gastos registrados es de solo lectura y las transferencias internas no se cuentan como gasto utilizado en la simulación. Las recomendaciones actualizan exclusivamente las cantidades proyectadas. No se atribuyen a Aprende comportamientos reales a partir de presupuestos simulados.

Se conserva la estructura, temas, categorías, recomendaciones y calendario de aportaciones. Las proyecciones se calculan a partir de ingresos proyectados y cantidades planificadas, sin usar el balance disponible real como base editable. La ayuda y los resúmenes distinguen proyección y realidad. Históricos y movimientos existentes se conservan; no se realizan migraciones SQL ni modificaciones de datos reales al actualizar el código. La nueva propiedad simulation es opcional en el JSON existente, compatible con respaldos anteriores.

Pruebas con SQLite en memoria y datos FICTICIOS comparan todas las tablas ajenas a los dos registros de planificación antes y después de guardar, copiar, editar y eliminar. Se comprueban separación personal/comercial, déficits, proyección independiente de fondos, recomendaciones, importes, gráficos, compatibilidad histórica, TypeScript y ESLint. El paquete conserva rutas, service worker y módulos ajenos, y solo cambia URLs de scripts que cambiaron o dependen de ellos. No hay navegador interactivo ni dispositivos físicos disponibles; no se afirma revisión física en Safari/iPad.
