# Home: Personal and Commercial balances and charts

Scope is Home only. The existing available-estimate banner is divided into equal Personal and Commercial columns. Two instances of the existing MonthlyCharts show each scope's income and expenses for the selected month, with the existing ring/horizontal/vertical and transaction controls. Wide screens show the charts side by side; narrow screens stack them for readability. Both graphs remain on the app background. Greeting, month control, actions, dictations shortcut, Top 3 and all other screens retain their behavior.

HomeBalancesAndCharts reads existing BusinessLedgerStore and money snapshots, without saving/reclassifying records. Its commercial projection reuses commercialAmount and the existing monthlySummary formula with copies for display only. It excludes deleted/stale entries, mismatched movement versions, personal/unknown commercial shares and other months, counts each movement once despite project allocations, and preserves the existing treatment of credit expenses. Personal summary is passed through unchanged. Existing recorded business percentages are not edited. No assumptions are made about bank balances or manual reserves; amounts remain estimates from recorded activity. A failed commercial read is shown as unavailable rather than an invented zero. Async results are keyed to the month and current personal snapshot, so stale responses cannot replace the current period.

Publication baseline is live Sites version 81, source 76f38f61662afbe5a0e00b30d5adf510f90bf8d8. scripts/patch-home-split-site.cjs modifies only factories 820 and 825: the Home summary receives existing personal chart rows/categories, and only the old balance banner node is replaced by the scoped Home panel. The newer published month-label helper and all other Home controls are retained byte-for-byte. Other factories, server/auth/API/sync code and financial persistence remain intact. Asset importers and service-worker cache URLs are versioned; unreferenced generated blobs are pruned. Reproduce by extracting that baseline worker to /tmp/edumoney-live81-worker.js.

Validation budget: 16/100 conservatively counted executions: 7 new Vitest cases, 2 existing Home navigation cases, 1 repeated responsive layout case, and three two-check artifact runs. The first artifact attempt exposed an incorrect mock ESM default-export shape, which was corrected; the two subsequent runs passed. Final generated-worker checks rendered a real asynchronous $200 commercial result alongside $700 personal, verified separate chart values, preserved business classification and existing month labels/actions/Top 3, and verified personal rows/categories are forwarded. Source tests cover cash/credit, mixed-use recorded shares, dates, stale/deleted entries, read errors and 390/768/1024 layouts. TypeScript, full ESLint, scoped post-change ESLint and worker syntax checks passed. No interactive browser/device QA available; no claim of physical-device validation. No new dependency, API call, schema change or migration.
